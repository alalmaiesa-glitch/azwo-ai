# AZWO Website V1 — Product Scope

## الهدف
تحويل هوية عَزْو من تصور بصري إلى منتج ويب فعلي يمكن اختباره مع المستخدمين وبناء الخدمات الخلفية عليه.

## الوحدات
1. Home / Value proposition
2. Verification input
3. Verification result / Claim map
4. Knowledge Library
5. History & Reports
6. Sources
7. Waqf profile
8. Account / Settings (visual placeholder)

## المرحلة التالية
- Authentication and organization workspaces.
- Backend API.
- Source registry database.
- Quran deterministic validator.
- Hadith/source adapters.
- Claim extraction.
- Evidence retrieval and ranking.
- Review workflow.
- PDF/Word ingestion.
- Audit logs and export.
- Admin console.

## مبدأ المنتج
عَزْو لا يصدر حكمًا نهائيًا لمجرد عدم العثور على دليل؛ بل يوضح نطاق البحث، حالة المصدر، وما يحتاج إلى مراجعة بشرية.
