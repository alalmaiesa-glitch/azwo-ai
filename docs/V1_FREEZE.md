# تَأْثِيل — V1 Feature Freeze

تاريخ التجميد: 23 سبتمبر 2026

## الهدف
تحويل النسخة الحالية من نموذج متعدد الموصلات إلى Public Beta مستقرة، قابلة للمراجعة، ولا تعرض نتيجة دون مصدر أو حدود واضحة.

## نطاق V1 المجمد
- أنواع المحتوى: نص، صورة، صوت، فيديو، مخطوط، وثيقة.
- المجالات: شرعي، علمي، أكاديمي، تاريخي، إعلامي، قانوني، أدبي، ثقافي، ومعرفة عامة.
- نقطة الدخول الوحيدة: Taatheel Router V1.
- بنية النتيجة الموحدة: `taatheel.result.v1`.
- الموصلات الحية المعتمدة حاليًا:
  - Dorar Hadith API
  - OpenAlex
  - Crossref
  - Internet Archive
  - Wikimedia Commons
  - IIIF Presentation
- لا يتم وصف البحث الوصفي للصور أو الصوت أو الفيديو بأنه Reverse Search أو Fingerprinting ما لم تُنفذ المطابقة الفعلية.

## حالات النتيجة المعتمدة
- DIRECT_MATCH
- STRONG_SUPPORT
- PARTIAL_SUPPORT
- CANDIDATE_SOURCE
- CONFLICT
- NOT_FOUND
- HUMAN_REVIEW

## مبادئ V1
1. لا Fixtures في المسار العام.
2. لا حكم بلا مصدر.
3. كل نتيجة تحمل Audit ID.
4. كل مصدر يذكر نوع المطابقة وحدودها.
5. سقوط موصل واحد لا يسمح باختلاق نتيجة بديلة.
6. الملفات المرفوعة تُحذف تلقائيًا بعد 24 ساعة عند تفعيل الرفع الإنتاجي.
7. Public Beta تبدأ دون تسجيل دخول، مع Rate Limiting.
8. أي ميزة جديدة بعد التجميد تذهب إلى Backlog V1.1.

## معايير قبول Public Beta
- Router موحد لجميع الأنواع الستة.
- Source Registry يميز connected / disabled / degraded / down.
- رفع ملفات فعلي واستخراج المحتوى/metadata.
- Audit Trail دائم وقابل للمراجعة.
- حماية APIs وRate Limiting.
- مراقبة الأخطاء والموصلات.
- سياسة خصوصية وشروط استخدام وصفحة مصادر.
- Test Suite من 150–200 حالة.
- اختبار مغلق مع 10–20 مستخدمًا قبل الإطلاق العام.

## ما تم إنجازه عند التجميد
- Unified Result Schema مفعّل.
- Router V1 مفعّل ومختبر على الحديث، النص العام، والصورة.
- سجل الموصلات في قاعدة البيانات محدّث للموصلات الحية.
- الواجهة مهيأة للمرور عبر Router V1 فقط.
