# Al-Makanez Discovery Connector — Design Spec

## الهدف
إضافة «المكانز» إلى تَأْثِيل كمصدر **اكتشاف وفهرسة** يساعد في العثور على المواد العلمية، دون معاملته كمصدر إثبات نهائي.

## التصنيف
- `source_id`: `SRC-007`
- `source_class`: `DISCOVERY_ONLY`
- `evidence_eligible`: `false` افتراضيًا
- `requires_provenance_resolution`: `true`

## موقعه في المسار

```text
User claim/content
  -> Retrieval Router
  -> Al-Makanez Discovery Connector
  -> candidate leads
  -> Source Resolver / Provenance Gate
       -> original/traceable source
       -> bibliographic verification
       -> rights/terms check
  -> evidence eligibility decision
  -> Evidence Reranker
  -> Verification Classifier
```

## ما الذي يستخرجه الـConnector
لكل نتيجة، إن أمكن:

```json
{
  "discovery_source_id": "SRC-007",
  "title": "...",
  "author": "...",
  "category": "...",
  "material_type": "book|thesis|article|audio|video|manuscript|unknown",
  "landing_url": "...",
  "outbound_url": "...",
  "host": "google_drive|telegram|library|publisher|unknown",
  "description": "...",
  "discovered_at": "...",
  "provenance_status": "LEAD_ONLY"
}
```

## بوابة التأصيل Provenance Gate

لا تتحول النتيجة إلى Evidence إلا بعد تحقق أكبر قدر ممكن من:

1. اسم المؤلف.
2. عنوان العمل.
3. المحقق أو المترجم عند وجوده.
4. دار النشر أو الجهة الأكاديمية.
5. رقم الطبعة وسنة النشر.
6. رقم الجزء والصفحة أو الموضع.
7. الرابط الأصلي أو مستودع موثوق يمكن تتبعه.
8. سلامة الملف وعدم كونه رابطًا مفقودًا أو نسخة مجهولة.
9. شروط الاستخدام وحقوق النشر عند الحاجة إلى التخزين أو العرض.

## حالات النتيجة

- `LEAD_ONLY`: وُجدت مادة لكنها لم تُؤصّل بعد.
- `TRACEABLE`: أمكن تتبع المادة إلى مصدر أو نسخة ذات بيانات واضحة.
- `VERIFIED_ORIGINAL`: تحقق الأصل وبياناته بما يسمح باستخدامه كدليل.
- `RIGHTS_RESTRICTED`: المصدر معروف لكن الاستخدام أو التخزين مقيد.
- `BROKEN_LEAD`: الرابط أو المادة غير متاحة.
- `HUMAN_REVIEW`: توجد بيانات متعارضة أو ناقصة تحتاج مراجعة بشرية.

## قواعد خاصة بتَأْثِيل

- لا يُعرض اسم «المكانز» للمستخدم بوصفه المرجع النهائي إذا أمكن الوصول إلى الأصل.
- لا يُقتبس وصف أو تصنيف آلي من الفهرس باعتباره حقيقة عن المادة دون تحقق.
- لا تُحمّل الملفات جماعيًا أو تُخزن دائمًا ما لم تكن شروط الاستخدام تسمح بذلك.
- Google Drive وTelegram وروابط المرايا تُعامل كوسائط وصول، لا كمرجع ببليوغرافي مستقل.
- في المواد الشرعية: يفضّل الوصول إلى الطبعة المحققة أو المصدر المعتمد قبل الحكم على النص.
- في المخطوطات: يجب حفظ بيانات الحفظ، رقم الحفظ، المكتبة، الناسخ/التاريخ إن وجدت.
- في الرسائل الجامعية: تُفضّل صفحة المستودع الجامعي أو الناشر الأكاديمي على نسخة متداولة منفردة.

## استراتيجية التنفيذ أثناء التحدي

### Phase 1 — Discovery
- بحث بالكلمات المفتاحية.
- استخراج النتائج والروابط الخارجية.
- تطبيع العنوان والمؤلف ونوع المادة.
- حفظ النتائج كـ `LEAD_ONLY`.

### Phase 2 — Resolution
- محاولة الوصول إلى المصدر الخارجي.
- استخراج بيانات ببليوغرافية.
- حساب درجة قابلية التتبع `provenance_score`.

### Phase 3 — Evidence Admission
القبول التلقائي كدليل فقط عند اجتياز شروط الثقة المحددة للمجال. وإلا:
- `HUMAN_REVIEW`
- أو تبقى المادة مجرد Lead.

## اختبار القبول

يجب أن يغطي الاختبار على الأقل:
- نتيجة صحيحة يمكن تتبعها إلى أصل.
- رابط Google Drive فقط دون بيانات نشر.
- رابط Telegram.
- ملف PDF بعنوان ناقص.
- مادة لها أكثر من مؤلف/طبعة.
- رابط ميت.
- مادة مخطوطة.
- رسالة جامعية.
- نتيجة لا علاقة لها بادعاء المستخدم.
- حالة لا يمكن فيها تحديد حقوق التخزين.

## حدود الـbaseline
هذه الوثيقة تصميمية فقط قبل 4 أكتوبر 2026. لا تحتوي على كود scraping أو retrieval حي، ولا تغيّر وصف الـbaseline بأن الوصلات الحقيقية لم تُنفذ بعد.
