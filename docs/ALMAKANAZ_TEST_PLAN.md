## Assertions إلزامية
1. `source_id=SRC-007` لا يدخل مصفوفة `evidence` مباشرة.
2. كل نتيجة من المكانز تبدأ بـ `provenance_status=LEAD_ONLY`.
3. أي ترقية إلى `VERIFIED_ORIGINAL` تتطلب مصدرًا آخر قابلًا للتتبع.
4. فشل حل المصدر لا يسبب اختلاق بيانات ببليوغرافية.
5. عدم وضوح الحقوق يمنع التخزين الدائم حتى لو كانت المادة قابلة للقراءة.
