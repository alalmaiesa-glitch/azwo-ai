# محرك عَزْو للتأصيل — v0.1

## الهدف
تحويل النص العربي إلى معلومات قابلة للتتبع، ثم توجيه كل نوع إلى المصدر المتصل المناسب.

## المسار الحالي
```text
النص
  ↓
تقسيم الجمل والاقتباسات
  ↓
تصنيف حتمي أولي
  ├─ قرآن → Tanzil / quran_verses
  ├─ حديث → الدرر السنية
  ├─ قول/نسبة علمية → مراجعة بشرية حاليًا
  └─ معلومة عامة → مراجعة بشرية حاليًا
  ↓
حالة التأصيل
  ↓
claims + evidence + reports
```

## كشف القرآن
- يبحث عَزْو عن الاقتباسات وصيغ مثل: «قال تعالى».
- أي اقتباس يمكن اختباره أيضًا ضد القرآن حتى لو لم يسبقه وسم صريح.
- يستخدم `search_quran_quote` مع تطبيع لغرض البحث فقط.
- النص المرجعي المخزن نفسه لا يُعدّل.
- النتيجة تعيد السورة والآية والنص العثماني والإصدار.

## كشف الحديث
- يلتقط صيغ النسبة إلى النبي ﷺ.
- يبني عبارة بحث قصيرة من متن الحديث.
- يبحث في API الدرر السنية.
- يقارن كلمات النص المرشح مع النتائج.
- ≥ 55% تشابه مفرداتي: مدعوم مبدئيًا.
- 25–54%: دعم جزئي + مراجعة بشرية.
- أقل من ذلك مع وجود نتائج: مراجعة بشرية.
- لا توجد نتائج: غير مسند ضمن البحث الحالي، وليس حكمًا ببطلان الحديث.

## الأقوال والمعلومات العامة
لا يصدر عَزْو حكمًا دون مصدر متصل. لذلك:
- نسبة قول إلى عالم → `human_review` حتى يتصل مصدر تراثي صالح.
- دعوى إجماع/اتفاق → `human_review`.
- معلومة عامة → `human_review` حاليًا.

- `reviews`

## مبدأ السلامة
`عدم العثور ≠ الخطأ`

الاستثناء الوحيد هو المطابقة الحرفية الصريحة داخل مصدر محدد؛ وحتى هناك تصف النتيجة نطاق البحث ولا تتحول تلقائيًا إلى فتوى أو حكم علمي شامل.
