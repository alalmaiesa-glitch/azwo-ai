# تحسين واجهة عَزْو — نسخة عرض المسابقة

تمت ترقية واجهة baseline في المستودع إلى مستوى عرض أولي للمسابقة، مع الحفاظ على شرط مهم: كل النتائج الحالية موسومة بوضوح على أنها بيانات تجريبية وليست تحققًا فعليًا.

## مبادئ التصميم
- عربية من اليمين إلى اليسار RTL.
- هوية هادئة: أخضر عميق، عاجي، وذهبي.
- إظهار مسار عَزْو لا إخفاؤه.
- كل بطاقة ادعاء تعرض: الادعاء، المصدر، الدليل، الملاحظة، وحالة العزو.
- تجنب لغة “صحيح/باطل” واستبدالها بحالات علمية أدق.

## عناصر العرض
- شاشة إدخال النص.
- مسار معالجة مرئي.
- تقرير ادعاءات وأدلة.
- عدادات لحالات العزو.
- تصدير JSON تجريبي.
- تحذير واضح أن النسخة الحالية Demo fixtures.

## ما سيضاف أثناء التحدي
- استبدال fixture engine بمحرك استخراج حقيقي.
- ربط مصادر فعلية مرخصة.
- إضافة تقرير Audit قابل للتصدير.
- إضافة شاشة نتائج Benchmark.
