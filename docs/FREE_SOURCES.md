# المصادر المجانية المتصلة بعَزْو

## 1. Tanzil — النص القرآني
- الحالة: **متصل ويعمل**
- الاستخدام: النص العثماني المرجعي للمطابقة الحتمية.
- الإصدار المخزن: **Uthmani Version 1.1**
- عدد الآيات في قاعدة عَزْو: **6236**
- الترخيص: Creative Commons Attribution 3.0.
- الشرط الأساسي: النص محفوظ حرفيًا ولا يُعدّل، مع إظهار Tanzil كمصدر والرابط إليه.

## 2. الدرر السنية — الموسوعة الحديثية
- الحالة: **متصل عبر Edge Function**
- الاستخدام: بحث الحديث وقت الطلب.
- API الرسمي: `https://dorar.net/dorar_api.json?skey=...`
- عَزْو لا ينسخ corpus كاملًا؛ يسترجع نتائج البحث وقت الطلب.

## 3. QuranEnc
- الحالة: **متصل عبر Edge Function**
- الاستخدام: قائمة الترجمات، ترجمة سورة، أو ترجمة آية.
- الالتزامات: عدم تعديل الترجمة، إظهار المصدر والناشر، المحافظة على الإصدار ومعلومات النسخة.

## 4. OpenITI
- الحالة: **مسجل، غير مفعل في المسار التجاري**
- الحجم الحالي المنشور: corpus تراثي كبير قابل للتنزيل.
- الترخيص: CC BY-NC-SA 4.0.
- سبب التقييد: شرط عدم الاستخدام التجاري.
- الخطة: إنشاء فهرس محلي منفصل للبحث غير التجاري/الوقفي، مع إبقاء استخدامه خارج الخدمات التجارية حتى مراجعة الترخيص.

## 5. المكتبة الشاملة
- الحالة: **مقيدة / Pending**
- تم إعداد Shamela Adapter، لكن لا يُفعّل حتى تتضح شروط API وحقوق الفهرسة والتخزين.
