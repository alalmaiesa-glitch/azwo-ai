# موقع تَأْثِيل — Website V1

هذه أول نسخة تشغيلية من واجهة **تَأْثِيل — اعرف أصل المحتوى**.

## التشغيل محليًا
من جذر المستودع:

```bash
python3 -m http.server 4173 --directory site
```

ثم افتح:

`http://localhost:4173`

## ما يعمل في V1
- واجهة عربية RTL متجاوبة.
- الصفحة الرئيسية وهوية تَأْثِيل.
- إدخال نص / ملف / رابط / صورة على مستوى الواجهة.
- اختيار المجال واللغة.
- تشغيل تحليل تجريبي.
- خريطة تأثيل بنتائج وحالات متعددة.
- نسخ التقرير وتنزيل JSON.
- المكتبة المعرفية.
- سجل عمليات التحقق.
- تعريف بوقف تَأْثِيل.
- تصميم مناسب للجوال وسطح المكتب.

## ملاحظة
نتائج التحقق في هذه النسخة **تجريبية** إلى أن يتم ربط Backend ومحرك عَزْو الداخلي ومصادر التأثيل.
