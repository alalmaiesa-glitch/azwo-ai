# موقع عَزْو — Website V1

هذه أول نسخة تشغيلية من واجهة **عَزْو — تأصيل المعرفة**.

## التشغيل محليًا
من جذر المستودع:

```bash
python3 -m http.server 4173 --directory site
```

ثم افتح:

`http://localhost:4173`

## ما يعمل في V1
- واجهة عربية RTL متجاوبة.
- الصفحة الرئيسية وهوية عَزْو.
- إدخال نص / ملف / رابط / صورة على مستوى الواجهة.
- اختيار المجال واللغة.
- تشغيل تحليل تجريبي.
- خريطة تأصيل بنتائج وحالات متعددة.
- نسخ التقرير وتنزيل JSON.
- المكتبة المعرفية.
- سجل عمليات التحقق.
- تعريف بوقف عَزْو.
- تصميم مناسب للجوال وسطح المكتب.

## ملاحظة
نتائج التحقق في هذه النسخة **تجريبية** إلى أن يتم ربط Backend ومحرك المصادر والتأصيل الحقيقي.
